# ⚖️ JurisSTMG — Site de Révision Droit 1ère STMG

Bienvenue sur votre plateforme complète de révision conçue spécialement pour le programme de **Droit en 1ère STMG** (Chapitre 1 : Le Droit & Chapitre 2 : Les Sources du Droit).

---

## 🚀 Comment lancer le site ?

1. Rendez-vous dans le dossier **`Bureau\Droit`**.
2. Double-cliquez simplement sur le fichier **`index.html`**.
3. Le site s'ouvre directement dans votre navigateur web préféré (Chrome, Edge, Firefox, etc.) sans aucune installation requise !

## 🌟 Fonctionnalités incluses

### 1. 📖 Le Cours Complet & Structuré
- **Chapitre 1 : Le Droit**
  - Les 2 fonctions (organiser et pacifier la société) avec exemples concrets.
  - Les 4 valeurs de la République (Liberté, Égalité, Solidarité, Laïcité).
  - Les 3 caractéristiques indispensables de la règle de droit (Légitime, Obligatoire, Générale).

  - Sources internationales (Traités, Article 55 de la Constitution, Règlements & Directives de l'UE).

  - La séparation des 3 pouvoirs (Législatif, Exécutif, Judiciaire).
